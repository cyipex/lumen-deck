Allowed tablets

Virtual monitor

The extra screen that the tablet shows as a second monitor. While it is on, Windows has a screen you cannot see and the mouse can wander onto it. Turning it off only detaches it – the driver stays installed.

Notifications on the tablet

Notifications from the PC (Discord, WhatsApp, Windows…) briefly show up on the tablet. Untick the apps you don't want there.

Extras

Optional tools, downloaded from their official sources with one click.

The second monitor also needs a virtual display in Windows: install the free Virtual Display Driver (VDD.Control → Install Driver), then press Win + P → Extend.

Earlier layouts

Lumen Desk keeps a copy of your pages and tiles before they change (one every 10 minutes, the last 30). If something looks reset, bring back an earlier one. Paired tablets stay paired.
